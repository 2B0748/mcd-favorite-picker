# 快速开始

## 0. 你需要什么

- 一个支持远程 MCP 的 AI 客户端：WorkBuddy、Cherry Studio、Cursor、Claude Code 等。
- 你自己的麦当劳 MCP Token（免费申请）。
- Python 3.10 及以上（脚本只用标准库，不需要 pip install）。

## 1. 申请麦当劳 MCP Token

1. 打开 <https://open.mcd.cn/mcp>。
2. 右上角「登录」，用手机号验证。
3. 进入「控制台」→ 点「激活」→ 同意服务协议。
4. 复制 Token。**这个 Token 等于你的点餐身份，不要发到任何公开地方。**

## 2. 配置连接器

在你所用客户端的 MCP 配置里加入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
```

三个最常见的失败原因：

| 报错 | 原因 |
|---|---|
| 405 | URL 写成了 `https://open.mcd.cn/mcp`（那是网页控制台），必须是 `https://mcp.mcd.cn` |
| 401 | `Bearer ` 后面的空格漏了，或 Token 已失效 |
| 连上但没有工具 | 客户端里还没点「信任」/「启用」 |

WorkBuddy 路径：左侧「专家·技能·连接器」→ 连接器 → 右上角「自定义连接器」→ 填入上面 JSON → 保存 → 回到列表点「信任」。

## 3. 安装 Skill

**WorkBuddy（脚本安装）**

```powershell
./install.ps1
```

装到 `%USERPROFILE%\.workbuddy\skills\mcd-favorite-picker`，已存在会先备份。

**手动安装**

把仓库里的 `skills/mcd-favorite-picker` 整个文件夹拷进你客户端的技能目录即可。

**不想装 Skill**

也能用：打开仓库目录，让 AI 直接读 `skills/mcd-favorite-picker/SKILL.md`，按里面的流程操作。

## 4. 开始用

新开一个会话（重要：老会话看不到新装的 Skill），然后正常说话就行：

```text
用麦门口味雷达。现在几点、我想吃板烧，帮我看看常点什么、怎么点最省。
先告诉我哪家店能买，不要下单。
```

第一次它会问你在哪个城市或哪家店，因为 `query-nearby-stores` 需要城市 + 关键词（你要是有收藏门店就不用）。

## 5. 常用问法

| 你说 | 它做什么 |
|---|---|
| 今天麦当劳吃什么 | 按当前时段 + 你的常点给一个主推 + 一个备选 |
| 我平时都点什么 | 只做偏好统计，不推荐 |
| 早上吃什么 | 走早餐线；10:00–10:29 会提醒收档时间 |
| 怎么点最便宜 | 四类方案比价，识别活动价，校验券 |
| 我有什么券能用 | 解析券包，逐张判断此刻能不能用 |
| 给我做张口味卡 | 生成可分享的画像卡（HTML / PNG） |

## 常见问题

**Q：为什么它说「样本不足」？**

`order-list` 只返回近期若干单。样本少于 5 单时，脚本会如实标注「参考性有限」，少于 8 单时负向偏好只作弱提示。多下几单、并且每次都带上 `--prefs` 累积，结论会越来越准。

**Q：为什么推荐的老款买不到？**

历史订单里的品可能已下架。实测下架品名与在售菜单的相似度不到 0.3，会被判为下架并改给同类替代。如果它没给替代而是硬报了个不存在的品，请提 Issue。

**Q：券显示可用，下单时却说不能用？**

脚本判断的是券面写明的四个条件（日期、星期、时段、渠道）。门店级限制（如某些门店不参与）不在这四项里，以官方下单页为准。

**Q：价格和我 App 里看到的不一样？**

脚本取的是查询当时门店菜单快照。活动价、时段价会变，脚本不会缓存价格。

**Q：能帮我下单吗？**

不能，这是故意的。Skill 明确停在下单前一步，只给方案和价格。

**Q：需要联网吗？**

需要。价格、菜单、券全部来自官方 MCP，本地只做统计和金额比较，绝不编造价格。
